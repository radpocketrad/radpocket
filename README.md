# RADPOCKET – Ankle AP Positioning Module

Static radiography learning interface for the ankle AP projection.

## Included
- Modern dark RADPOCKET interface
- AP positioning visual
- Patient position, central ray and evaluation cards
- AP / Mortise / Lateral switcher
- Responsive layout

## GitHub Pages
Upload the files to the root of the repository, then go to Settings → Pages → Deploy from a branch → main → /(root).
